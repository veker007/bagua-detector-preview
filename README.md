# 八卦检测仪 · 在线演示成品

此仓库仅存放可直接运行的演示网页，包含三维模型、Type-C 插拔供电、颜色卡模拟检测、创意说明、Hairline 互动拆解与结构线稿。

结构页包含「01 外观三视图」「02 内部拆解图」「03 Hairline SVG 动画」三个选项。精细 SVG 支持开盖、Type-C 插拔、插卡检测、零件放大、明暗切换与自动演示。

- `index.html`：自包含的演示网页，无需额外安装依赖。
- `.nojekyll`：用于 GitHub Pages 的静态发布配置。

演示中的正常 / 异常和频率均为模拟结果，用于课堂与科创展示。

完整 TypeScript 源码、设计报告参考图及开发文件保存在单独的私有仓库中。
